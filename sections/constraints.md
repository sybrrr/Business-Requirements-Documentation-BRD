# 12. Constraints

| Constraint | Impact |
|---|---|
| HIPAA compliance | All data handling must meet regulatory requirements |
| SMART EHR integration | Limited to supported HL7 message types |
| MuleSoft API availability | Dependent on vendor schedule |
| Clinical staff availability | UAT must work around patient care schedules |
| Budget | Limited to approved funding |
| Timeline | Launch must align with quarterly release cycle |
| Documentation standards | Must follow DIA document control policies |
