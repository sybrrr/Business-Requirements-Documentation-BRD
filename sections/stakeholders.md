# 4. Stakeholders

| Stakeholder | Role | Interest |
|---|---|---|
| Director, IT Applications | Business Owner | Delivery, compliance, budget |
| Director, Clinical Operations | Clinical Owner | Clinical workflow fit, adoption |
| Compliance Officer | Regulatory Oversight | HIPAA, SOC 2, ISO 27001 |
| Product Owner, MyndWell | Product Direction | Feature prioritization |
| Clinical Staff (Counselors, Nurses) | End Users | Usability, accuracy, speed |
| Intake Coordinators | End Users | Patient data accuracy |
| IT Security Team | Security Oversight | Access controls, encryption |
| Software Development Team | Build & Delivery | Requirements clarity |
| QA Team | Testing | Test coverage, UAT |
| Vendor (SMART Integration) | Third Party | Interface specifications |
| Executive Leadership | Sponsorship | ROI, outcomes |
