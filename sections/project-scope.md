# 3. Project Scope

## In Scope

- MyndWell dashboard enhancements for searching, filtering, and viewing patient relapse predictions
- Integration with the SMART EHR system for real-time patient data
- HL7 message exchange for patient demographics, admission, and medication data
- Data mapping and interface requirements documentation
- User feedback mechanism (thumbs up / thumbs down) to improve AI predictions
- Training materials, job aids, and user documentation
- UAT and regression testing
- Compliance validation for HIPAA, SOC 2, and ISO 27001

## Out of Scope

- Changes to the underlying machine learning model
- Modifications to the SMART EHR system itself
- Billing, claims, or revenue cycle functionality
- Mobile application development
- Patient-facing interfaces
