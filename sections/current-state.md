# 5. Current State

## Current Process

1. Clinicians log in to separate systems to review patient history
2. Relapse risk is assessed manually based on clinical judgment
3. No consolidated cross-facility view exists
4. Risk levels are not standardized across facilities
5. Medication dosage information is reviewed in a separate system
6. No feedback loop exists to improve prediction accuracy

## Current Pain Points

| Pain Point | Impact |
|---|---|
| Manual review is time-consuming | Delays intervention |
| No cross-facility visibility | Missed high-risk patients |
| Inconsistent risk assessment | Uneven care quality |
| Separate systems for data | Increased error risk |
| No AI feedback mechanism | Predictions do not improve |
| Limited search capability | Clinicians cannot find patients quickly |
